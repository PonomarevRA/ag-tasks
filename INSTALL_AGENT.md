# Install ag-tasks with an agent

[Русский](#русский)

Give the following task to your local agent:

> Install ag-tasks from https://github.com/PonomarevRA/ag-tasks using the source instructions in README.md. Use a dedicated virtual environment and a separate data directory for the first check. Read skills/ag-tasks/SKILL.md, compare the complete skill folder with the copy my client uses and preserve any customizations. Install the skill if authorized. Register the local stdio MCP using the environment's absolute Python path and the same data directory as the running service. Preserve my other MCP servers. Reconnect and actually call tasks_capabilities. Report the install and data paths, the returned version and instance ID, and whether the client discovered the skill.

## Русский

Передайте локальному агенту это задание:

> Установи ag-tasks из https://github.com/PonomarevRA/ag-tasks по README.ru.md. Создай отдельное виртуальное окружение и отдельный каталог данных для первой проверки. Прочитай skills/ag-tasks/SKILL.md, сравни папку навыка целиком с копией моего клиента и сохрани пользовательские правки. Установи навык, если это разрешено. Подключи локальный stdio MCP с абсолютным путём к Python из окружения и тем же каталогом данных, что у сервиса. Сохрани другие MCP-серверы. Переподключись и фактически вызови tasks_capabilities. Сообщи пути установки и данных, версию, ID экземпляра и обнаружил ли клиент навык.
