## [0.8.5]

### Русский

- ag-tasks проверяет наличие новых версий в фоне и предлагает обновиться после завершения работы агента.
- Проверку и страницу обновлений можно открыть из меню «Справка».
- Карточка показывает следующий шаг и возвращает фокус к исходной строке при закрытии.
- Готовые результаты остаются в очереди независимого ревью, пока ожидают проверки.

### English

- ag-tasks checks for new versions in the background and suggests updating after the agent finishes its work.
- Use the Help menu to check for updates and open the official release page.
- Task details show the next action and return focus to the original row when closed.
- Submitted results stay in the independent review queue while they await review.
