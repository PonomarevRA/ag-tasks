# ag-tasks

[English](README.md) · [Установка с агентом](INSTALL_AGENT.md#русский)

ag-tasks — локальный трекер задач для людей и агентов. В нём есть канбан, граф задач, обзор по проектам, рабочие сессии и ревью. Cursor, Codex и другие клиенты с поддержкой локального stdio MCP используют один набор инструментов. Слияние Git одобряет человек.

## Установка из исходников

Понадобятся Git и Python 3.11 или новее. На macOS и Linux выполните:

```sh
git clone https://github.com/PonomarevRA/ag-tasks.git
cd ag-tasks
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/python -m ag_tasks --port 8895
```

На Windows создайте окружение командой `py -3 -m venv .venv` и вместо `.venv/bin/python` используйте `.venv\Scripts\python.exe`. Сохраните каталог исходников. Откройте [http://127.0.0.1:8895](http://127.0.0.1:8895) в браузере. Если порт занят, выберите свободный и откройте соответствующий адрес. Данные сервиса хранятся в отдельном пользовательском каталоге. Для чистой проверки запустите сервис с `--data-dir`, указав новый каталог.

Для нативного окна установите зависимости командой `python -m pip install -e ".[desktop]"` в том же окружении и запустите `python -m ag_tasks --desktop` вместо браузерного сервера. На Linux для окна также нужны системные библиотеки Qt WebEngine. Требования платформ и сборка установщиков описаны в [руководстве по поставке](docs/engineering/desktop-distribution.md).

## Подключение агента

1. Оставьте ag-tasks запущенным. Зарегистрируйте в настройках клиента stdio-сервер `ag-tasks`. Команда — **абсолютный путь** к Python из виртуального окружения, аргументы — `["-m", "ag_tasks", "--mcp"]`. Если сервис запущен с `--data-dir`, добавьте этот параметр с тем же абсолютным путём в аргументы MCP.
2. Переподключите клиент и попросите вызвать `tasks_capabilities({})`. В ответе проверьте имя `ag-tasks` и ID нужного экземпляра. Команда `python -m ag_tasks --agent-tools` из того же окружения показывает актуальные схемы.
3. Скопируйте целиком папку [`skills/ag-tasks/`](skills/ag-tasks/) в каталог навыков клиента. Типичные пользовательские пути — `~/.codex/skills/`, `~/.cursor/skills/`, `~/.claude/skills/`. Сохраните локальные правки навыка и обновите список навыков в клиенте. [Готовое задание агенту](INSTALL_AGENT.md#русский) включает установку и проверку.
